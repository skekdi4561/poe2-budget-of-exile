# AI policy of this fork

**The file `AI_POLICY.md` in this repository is upstream's, kept verbatim. It is not ours
and we have not edited it.** It says code generated by LLMs or agents is not accepted
in the upstream repository. We respect that, and this document states our own position
separately rather than overwriting theirs.

## What this fork does

This fork **is** developed with AI pair programming (Claude).

Because upstream does not accept agent-generated code, **this fork never opens pull
requests against Exiled Exchange 2.** Code flows one way: we merge from upstream, we do
not push to it. If something we fixed would help upstream, we describe the problem in
plain language (an issue, or a translation suggestion on their Weblate) and leave the
implementation to them.

## What that means for you

- Every release is built by CI from this public repository; the build is reproducible.
- The test suite is part of the deal, not decoration — behaviour we change is covered by
  tests, and we mutation-check the tests that guard anything subtle.
- If you would rather not run AI-assisted software, that is a legitimate choice.
  [Exiled Exchange 2](https://github.com/Kvan7/Exiled-Exchange-2) is the upstream project
  and does what this fork does, minus the market-curve widget.

## Not affiliated

This is an unofficial fork. It is not built, endorsed, or supported by the upstream
maintainer. **Do not report bugs in this build to the Exiled Exchange 2 issue tracker** —
use [this repository's issues](https://github.com/skekdi4561/poe2-budget-of-exile/issues).

# 이 포크의 AI 정책 (한국어)

**이 저장소의 `AI_POLICY.md` 는 원작(Exiled Exchange 2)의 파일이고 원문 그대로입니다.
우리 것이 아니며 고치지 않았습니다.** 그 문서는 LLM·에이전트가 생성한 코드를 원작
저장소에서 받지 않는다고 밝히고 있습니다. 그 입장을 존중해, 우리 정책은 그 파일을
덮어쓰지 않고 이렇게 따로 적습니다.

이 포크는 AI(Claude) 페어 프로그래밍으로 개발됩니다. 원작이 에이전트 코드를 안 받으므로
**업스트림에 PR 을 보내지 않습니다.** 코드는 한 방향으로만 흐릅니다 — 우리가 원작에서
받아오고, 원작으로 올리지는 않습니다. 원작에도 도움이 될 것을 발견하면 구현을 보내는 대신
문제를 말로 설명합니다(이슈, 또는 원작 Weblate 의 번역 제안).

AI 가 관여한 소프트웨어를 쓰지 않으시겠다면 그건 정당한 선택입니다.
[Exiled Exchange 2](https://github.com/Kvan7/Exiled-Exchange-2) 가 원작이고, 이 포크에서
시장 곡선 위젯을 뺀 것과 같습니다.

이 포크는 **비공식**입니다. 원작 제작자가 만들거나 보증하거나 지원하지 않습니다.
**이 빌드의 버그를 Exiled Exchange 2 이슈 트래커에 올리지 마세요** —
[이 저장소의 Issues](https://github.com/skekdi4561/poe2-budget-of-exile/issues) 를 써 주세요.
