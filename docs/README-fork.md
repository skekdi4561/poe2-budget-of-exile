# 이 폴더는 이 포크에서 쓰지 않습니다

원작(Exiled Exchange 2)의 VitePress 문서입니다. 포크는 이걸 배포하지 않습니다 —
`.vitepress/config` 에 원작 버전(0.15.8)과 원작 릴리스 링크가 박혀 있어서,
우리 이름으로 게시되면 잘못된 정보를 우리가 말하는 꼴이 됩니다.

그래서 배포 워크플로(`.github/workflows/pages.yml`)를 지웠습니다.
폴더 자체는 남겨둡니다: 히스토리에 이미 있어 지워도 클론이 안 줄고,
원작이 계속 관리하는 경로라 지우면 upstream 병합 때마다 충돌합니다.

이 포크의 문서는 저장소 루트 README.md 입니다.
